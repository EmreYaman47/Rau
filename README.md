# NORTHSTAR AI Workshop

Render-ready Node/Express landing page.

Run: `npm install && npm start`

Render: connect this GitHub repository as a Web Service, build `npm install`, start `npm start`.

Signups are appended to `data/registrations.txt` by the server. **Render's default filesystem is ephemeral**, so data may disappear on restart/redeploy. For durable collection, configure persistent storage and `DATA_DIR` or switch to an external database. The free instance is suitable for demonstration, not reliable long-term storage.
